# timeswap

학기 중 시간표 변경(수업 교환) 지원 시스템. 저장소 이름은 작업용 가칭이다.

교사 출장, 연수, 병가로 생기는 결강을 학교는 "교체 우선, 실패 시 보강" 규정으로 처리한다.
교체(수업 교환) 탐색이 수작업이라 포기가 잦고, 포기는 보강 수당과 수업 결손으로 이어진다.
이 시스템은 실행 가능한 교환안을 자동으로 찾아 근거와 함께 추천한다.
